# My Dotfiles

## Instructions

Ensure you have the git and stow packages installed.

```bash
# Clone it to $HOME directory
git clone https://github.com/akza07/dotfiles.git ~/

# Set current working directory to dotfiles
cd dotfiles

# Symlink everything in current directory to $HOME
stow .

```

Done! Bye
